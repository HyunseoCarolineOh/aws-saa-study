## 문제 탭

### 🎯 랜덤 풀기 — 일상 학습 모드
매일 꾸준히 풀 때 가장 효과적인 모드입니다. 한 번도 안 푼 문제를 우선 출제하고, 틀린 문제는 SM-2 알고리즘에 따라 복습 일정에 자동 등록됩니다.

- 안 푼 문제 우선 출제
- SM-2 알고리즘으로 복습 타이밍 자동 계산
- 제한 시간 없음 / 즉시 해설 확인

#### 📌 이어서 풀기
앱을 닫았다가 다시 들어와도 마지막으로 풀던 위치에서 이어서 풀 수 있습니다. 문제 탭 진입 시 "이어서 풀기 (N / M번째 문제)" 버튼이 표시됩니다. 처음부터 새로 시작하려면 "새로 시작" 버튼을 누르세요.

#### 💡 해설 기능
답을 제출하면 문제 하단에 해설 영역이 나타납니다. **3개 탭**으로 구성됩니다:

| 탭 | 내용 |
|----|------|
| 해설 | 핵심 이유 요약 — 왜 이 선택지가 정답인지 간결하게 설명 |
| 상세 풀이 | AWS 공식 문서 기반 심층 해설. 오답 선지의 오류 이유도 포함 |
| 관련 서비스 | 문제에 등장하는 AWS 서비스 목록. 탭 누르면 개념 사전으로 이동 |

> ⚠️ 해설은 답 제출 전에는 표시되지 않습니다.

#### 📝 오답노트 추가 기능
문제 풀이 중 중요한 텍스트를 발견하면 그 자리에서 노트로 저장할 수 있습니다.

**저장 방법:**
1. 문제 본문, 해설, 상세 풀이 중 텍스트를 **길게 누르거나 드래그**
2. 화면에 팝오버가 나타나면 **"오답노트 저장"** 버튼 탭
3. 메모 입력 시트에 내 생각·보충 설명 작성 후 저장

**확인·관리:**
- 저장된 노트는 **복습 탭 > 오답노트**에서 모아볼 수 있습니다
- 각 노트에는 문제/해설/상세 풀이 중 어디서 저장했는지 라벨이 표시됩니다
- 텍스트 검색, 메모 편집, 삭제 기능을 지원합니다

### 📝 모의고사 — 실전 시험 시뮬레이션
타이머를 켜고 도메인별 가중 비율로 문제가 출제됩니다. 결과 화면에서 도메인별 점수와 합격 여부를 확인할 수 있습니다.

- 실전 타이머 제한
- 도메인별 가중 출제
- 결과 리포트 및 합격 기준 비교
